# Iリスト帳票アプリ

自動車型式の **適合必要法規** と **認証取得実績（認可書）** を管理する帳票アプリ。
規制日に対して各型式が適合すべき法規の漏れを自動検出し、認証取得実績を一元管理する。
エクセルの「塗り絵」運用を、リレーショナルなデータモデルと自動判定に置き換える。

詳しい機能・構成・判定ロジックは [`ilist-app/README.md`](./ilist-app/README.md) を参照。

## クイックスタート（Mac）

Node.js が必要（未インストールなら https://nodejs.org からLTS版を入れる）。

```bash
cd ilist-app
npm install      # 初回だけ
npm run dev      # 画面(Vite)とAPIサーバ(SQLite保存)を同時起動
```

ターミナルに出る `http://localhost:5173` をブラウザで開く。止めるときは `Ctrl + C`。

## ⚠️ データについての注意

- 本リポジトリに含まれるデータは **すべてダミー・架空のサンプル** です（他社・架空の型式を題材にした推測値）。実際の社内データ・実車型式・実際の認可書番号などの実業務情報は含まれていません。
- 本アプリ・本リポジトリに **実業務情報を追加しないでください**。会社導入レベルでの利用にはセキュリティ・情報システムの承認が別途必要です。
